六款小米 Alive 壁纸改为内置，安装后即可离线选择，不再需要单独导入场景 APK。

- 内置月球、雪山、几何、土星环、地球家园和红色火星；继续使用原版渲染器、列表、预览和落地点页面。
- 共享相同数据块并使用 XZ 无损压缩，六款场景资源由约 414.6 MiB 降至 314.9 MiB，节省约 99.6 MiB。完整安装包约 570.4 MiB。
- 首次打开在后台准备所选场景，并显示等待提示；之后复用缓存。已有的有效原包仍可复用，损坏的缓存会从内置数据恢复。没有网络下载或持续解压任务。
- 还原后的 APK 与原包 SHA-256 完全一致，保留全部纹理、落地点、时间变化和原版代码。锁屏仍由 ColorOS 处理，只保留独立的小米 AOD 时钟淡入淡出。

主力机空目录测试通过 46 项检查，覆盖六款原包还原、复用、错误回滚、损坏修复和并发准备；原有 198 项时钟、资源与动画检查也通过。首次准备大多约 2～4 秒，火星约 19 秒，耗时因设备而异。

需要 Root 与 LSPosed。自实现代码采用 MIT 许可证，官方程序及素材保留原有权利；XZ Java 源码采用 0BSD，详见 THIRD_PARTY.md。
