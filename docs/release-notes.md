新增 Vivo Alive 壁纸和时钟，并修复编辑预览、息屏恢复与图片选择流程。

- Vivo Alive：液态、趣味光栅、闪卡复用原版渲染器，支持灵敏度、自选素材和恢复默认搭配；图集光栅可分别选择封面与光栅图片，视频光栅支持封面与视频。
- Vivo 时钟与实时玻璃、模糊效果接入 ColorOS 编辑器；修复预览数字截断，日期文字不再套用玻璃效果。
- 调整四种扩展时钟效果的预览、保存和应用路径；改善息屏到亮屏的亮度衔接。
- 魅族 Alive 自选照片新增全屏比例裁切，支持双指缩放、拖动和复位，取消不改变原配置；留光相框保留原有裁切方式。
- 增加息屏可见性和传感器恢复检查，处理系统息屏接口暂时不可用时的重试。

已在主力机完成裁切、原版渲染器和时钟预览相关测试。长时间黑屏后偶发的光栅恢复问题已增加恢复处理，尚未复现原始极低概率场景。

需要 Root 与 LSPosed；从旧版更新后请正常重启并解锁一次，让 SystemUI 加载时钟模块。
